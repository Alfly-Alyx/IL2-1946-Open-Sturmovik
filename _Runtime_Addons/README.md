# Add-ons actifs en parallele

Ce dossier est provisoire. Il regroupe les programmes qui restent actifs en parallele d'IL-2 et agissent sur son environnement d'execution plutot que sur les classes du moteur.

- `Gapa` modifie en temps reel la courbe gamma/LUT de l'affichage Windows ; son effet n'est pas limite a IL-2.

Gapa n'est pas un mod moteur comme AOC. Il reste desactive par defaut jusqu'a un essai controle du retour aux couleurs normales, avec et sans HDR.
