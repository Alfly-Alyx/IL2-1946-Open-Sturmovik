### Version 1.15

- IL-2 4.08m, 4.09b et 4.09m ;
- jeu original ou Open Sturmovik ;
- modes sans 6DOF et avec 6DOF ;
- HUD Standard ou Immersion ;
- français, anglais, allemand, russe, tchèque, hongrois et polonais ;
- plein écran adapté automatiquement à la résolution native ;
- raccourcis pour le jeu, le switcher et les utilitaires.

La configuration initiale est **4.09m, Open Sturmovik sans 6DOF, HUD standard et français**.

### Installation

Une installation existante d'IL-2 Sturmovik 1946 en version 4.07m, 4.08m, 4.09b ou 4.09m est nécessaire.

1. Téléchargez Setup.exe et les huit fichiers BIN de la [release v1.15](https://github.com/Alfly-Alyx/IL2-1946-Open-Sturmovik/releases/tag/v1.15).
2. Placez les neuf fichiers dans le même dossier.
3. Lancez **Open-Sturmovik-1.15-Setup.exe**.
4. Sélectionnez le dossier du jeu.

Fermez le jeu avant de changer de profil avec le switcher.

## English

Open Sturmovik is a community expansion for **IL-2 Sturmovik 1946**. It brings together the enhanced game, a version switcher and several utilities in a single installation.

### Version 1.15

- IL-2 4.08m, 4.09b and 4.09m;
- original game or Open Sturmovik;
- without 6DOF and with 6DOF modes;
- Standard or Immersion HUD;
- French, English, German, Russian, Czech, Hungarian and Polish;
- full-screen display automatically adjusted to the native resolution;
- shortcuts for the game, switcher and utilities.

The initial configuration is **4.09m, Open Sturmovik without 6DOF, standard HUD and French**.

### Installation

An existing IL-2 Sturmovik 1946 installation running 4.07m, 4.08m, 4.09b or 4.09m is required.

1. Download Setup.exe and all eight BIN files from the [v1.15 release](https://github.com/Alfly-Alyx/IL2-1946-Open-Sturmovik/releases/tag/v1.15).
2. Place all nine files in the same folder.
3. Run **Open-Sturmovik-1.15-Setup.exe**.
4. Select the game folder.

Close the game before switching profiles.
