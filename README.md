## Français

### Open Sturmovik, c'est quoi ?

Open Sturmovik est un pack complet de mods et de contenus pour **IL-2 Sturmovik 1946**.

Il rassemble dans une version cohérente et prête à jouer des appareils, cartes, campagnes, missions, sons, améliorations visuelles, options d'immersion et utilitaires créés pour IL-2 1946.

Le pack est principalement construit autour d'IL-2 4.09m, tout en permettant de jouer avec les versions 4.08m et 4.09b ou de revenir au jeu original.

Open Sturmovik n'est pas un jeu autonome. IL-2 Sturmovik 1946 doit déjà être installé.

### Ce que propose la version 1.15

Le switcher donne accès à neuf profils :

| Version | Jeu original | Open Sturmovik sans 6DOF | Open Sturmovik avec 6DOF |
| --- | --- | --- | --- |
| 4.08m | Oui | Oui | Oui |
| 4.09b | Oui | Oui | Oui |
| 4.09m | Oui | Oui | Oui |

Le joueur peut également choisir :

- le HUD Standard ou Immersion ;
- le français, l'anglais, l'allemand, le russe, le tchèque, le hongrois ou le polonais ;
- les utilitaires fournis pour les appareils, les commandes, les missions, le bombardement, la météo et la navigation.

Le jeu est configuré en plein écran à la résolution native de l'écran.

### Configuration initiale

Après l'installation, Open Sturmovik démarre avec :

- IL-2 4.09m ;
- Open Sturmovik sans 6DOF ;
- HUD standard ;
- langue française.

Le jeu doit être fermé avant de changer de profil avec le switcher.

### Installation

La version 1.15 est une installation complète d'Open Sturmovik. Ce n'est pas un patch pour une ancienne version du pack.

Elle s'installe par-dessus une installation d'origine d'IL-2 Sturmovik 1946 en version 4.07m, 4.08m, 4.09b ou 4.09m. Le dossier choisi ne doit pas déjà contenir Open Sturmovik.

1. Téléchargez **Open-Sturmovik-1.15-Setup.exe** et les huit fichiers BIN depuis la [release v1.15](https://github.com/Alfly-Alyx/IL2-1946-Open-Sturmovik/releases/tag/v1.15).
2. Placez les neuf fichiers dans le même dossier.
3. Lancez **Open-Sturmovik-1.15-Setup.exe**.
4. Sélectionnez le dossier d'IL-2 Sturmovik 1946.

## English

### What is Open Sturmovik?

Open Sturmovik is a complete pack of mods and content for **IL-2 Sturmovik 1946**.

It brings together aircraft, maps, campaigns, missions, sounds, visual enhancements, immersion options and utilities in a consistent, ready-to-play edition of IL-2 1946.

The pack is mainly built around IL-2 4.09m while also allowing players to use versions 4.08m and 4.09b or return to the original game.

Open Sturmovik is not a standalone game. IL-2 Sturmovik 1946 must already be installed.

### What version 1.15 provides

The switcher provides nine profiles:

| Version | Original game | Open Sturmovik without 6DOF | Open Sturmovik with 6DOF |
| --- | --- | --- | --- |
| 4.08m | Yes | Yes | Yes |
| 4.09b | Yes | Yes | Yes |
| 4.09m | Yes | Yes | Yes |

Players can also choose:

- the Standard or Immersion HUD;
- French, English, German, Russian, Czech, Hungarian or Polish;
- the included utilities for aircraft information, controls, missions, bombing, weather and navigation.

The game is configured for full-screen display at the screen's native resolution.

### Initial configuration

After installation, Open Sturmovik starts with:

- IL-2 4.09m;
- Open Sturmovik without 6DOF;
- standard HUD;
- French language.

Close the game before changing profiles with the switcher.

### Installation

Version 1.15 is a complete Open Sturmovik installation. It is not a patch for an older version of the pack.

It installs over an original IL-2 Sturmovik 1946 installation running 4.07m, 4.08m, 4.09b or 4.09m. The selected folder must not already contain Open Sturmovik.

1. Download **Open-Sturmovik-1.15-Setup.exe** and all eight BIN files from the [v1.15 release](https://github.com/Alfly-Alyx/IL2-1946-Open-Sturmovik/releases/tag/v1.15).
2. Place all nine files in the same folder.
3. Run **Open-Sturmovik-1.15-Setup.exe**.
4. Select the IL-2 Sturmovik 1946 folder.
