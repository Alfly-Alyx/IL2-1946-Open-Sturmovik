# Ameliorations actives du jeu

Ce dossier regroupe provisoirement les programmes externes qui ameliorent directement une fonction visible d'IL-2 pendant une partie.

- `San's IL2 FOV Changer` agit sur le champ de vision pendant l'execution du jeu.

Ce programme n'est pas un mod moteur comme AOC : il n'est pas charge comme classe ou ressource du moteur IL-2. Il exige toutefois davantage de precautions que les utilitaires de `_Utilities`, car une mauvaise configuration peut agir sur le processus du jeu.

Il reste desactive par defaut jusqu'a validation sur une installation de test.
